Sites

Choose the sites where PlantUML diagrams are rendered. Reload an open page after a change.

Built-in sites

Always allowed by the extension. Turn one off to stop rendering diagrams there.

    Local files also need the Allow access to file URLs switch on the extension's page in chrome://extensions.

    Your sites

    Add a site that shows plantuml code blocks, for example a self-hosted GitLab, Gitea or a documentation site. The browser asks for permission to run on the site when you add it, and it can be removed here at any time.

      A site that covers every address (*://*/*) lets the extension run on all the pages you visit.
